Open source tools for AI workflows, browsers and cars.

  • Add to NotebookLM: a free Chrome extension that imports web pages, YouTube videos, playlists, channels and comments into NotebookLM.
  • BYDMate: an app for BYD DiLink head units with split screen, navigation on the instrument cluster, a trip and charging journal, and ABRP telemetry.
  • gemini-webapi-mcp: an MCP server for Google Gemini that provides image generation, editing and chat through browser cookies, without API keys.
  • senior-fable: tech-lead orchestration for Claude Code, where the top model keeps architecture and decisions while cheaper subagents do the routine work and the digging.
  • Soroka: a personal Telegram knowledge base: forward anything, search it from a chat, with an MCP server for Claude.
  • premortem: a Claude Code skill that finds the concrete ways a plan could fail before you commit to it.
  • telegram-business-bridge: connects an AI agent to your personal Telegram through the official Business API, with every reply waiting for your approval.
  • claude-statusline: a status line for Claude Code showing the model, context usage, usage limits, git branch and session time.
